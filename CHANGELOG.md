# Changelog

## 0.2.0 - 2026-08-04

- Renamed the project from MoonTrace to MoonAttest after a public ecosystem duplication scan.
- Replaced workflow execution, retry, scheduling, and event replay features with normalized acceptance evidence.
- Added policy predicates, weighted verdicts, structural validation, provenance audit, and file boundaries.
- Added deterministic proof bundles, evidence timeline chains, revision comparisons, and Markdown/JSON reports.
- Added evidence conflict reconciliation, acceptance metrics, a line manifest, and five CLI views.
- Removed the generated catalog used to inflate the earlier source count; the current codebase exceeds 4,000 authored MoonBit lines.
- Expanded the executable regression suite and updated CI, README, technical design, examples, and application materials.

## 0.1.0 - 2026-08-04

- Initial MoonTrace workflow audit prototype.
- Added workflow DSL, event fixtures, release checks, reports, CLI demo, and CI configuration.
